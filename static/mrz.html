MATHEMATICAL VERIFICATION SPECIFICATION

The ICAO 7-3-1 Modulo 10 Check Digit Algorithm

Every check digit in an ICAO Doc 9303 machine-readable travel document is computed using a cyclic repetition of weighting factors: 7, 3, 1.

Formula Definition:
C = (∑ [Value(Char[i]) × Weight[i % 3]]) mod 10
  • Weight sequence: W[0] = 7, W[1] = 3, W[2] = 1
  • Filler character < has a numeric value of 0
  • Digits '0'–'9' evaluate to their natural decimal values 0–9
  • Letters 'A'–'Z' evaluate sequentially: A=10, B=11, ..., Z=35

ICAO Doc 9303 Machine Readable Specifications

Complete breakdown of standard document geometries, OCR-B optical characteristics, and international diacritics transliteration tables.

Part 4: TD3 (Passports)

2 Rows × 44 Columns

Standard for all international machine readable passports. Line 1 encodes document type ('P<'), issuing state (3-letter ISO 3166), and holder surname followed by double chevron ('<<') and given names. Line 2 encodes document number, check digit, nationality, DOB, sex, expiry, optional data, and composite check digit.

Part 5: TD1 (ID Cards & PR)

3 Rows × 30 Columns

Standard credit card sized (ID-1) travel documents, national identity cards, and permanent resident cards (such as the Canada PR Card). Line 1 holds document type, country, doc number, and optional data 1. Line 2 holds DOB, sex, expiry, nationality, optional data 2, and composite check digit. Line 3 contains holder names.

Part 7: MRV Visas

Format A (2×44) & B (2×36)

Machine Readable Visas. MRV-A is full-page passport sticker format (2×44 chars). MRV-B is compact format (2×36 chars). Both begin with 'V' indicator and lack overall composite check digits due to different issuing authority security structures.
